# Как устроен код приложения

Проект специально оставлен небольшим: один экран, одна Java-активность, стандартные элементы Android.

## Где что находится

| Файл | Назначение |
|---|---|
| `app/src/main/java/com/circlecalculator/MainActivity.java` | Читает радиус, проверяет его, вызывает расчёт и показывает ответ. |
| `app/src/main/res/layout/activity_main.xml` | Описывает экран: заголовок, поле радиуса, кнопку и три строки результата. `ScrollView` позволяет прокрутить экран в альбомной ориентации. |
| `app/src/main/res/values/strings.xml` | Все надписи интерфейса и сообщения об ошибках. |
| `app/src/main/res/values/colors.xml` | Цвета светлой темы. |
| `app/src/main/res/values-night/colors.xml` | Цвета тёмной темы. |
| `app/src/main/res/values/themes.xml` и `values-night/themes.xml` | Настройка светлого и тёмного оформления. |
| `app/src/main/res/drawable/ic_circle.xml` | Векторная иконка с изображением окружности и радиуса. |
| `app/src/main/AndroidManifest.xml` | Имя главного экрана, название и иконка приложения. |

## Что происходит при нажатии кнопки

1. `onCreate()` находит компоненты экрана по идентификаторам и связывает кнопку с методом `calculate()`.
2. `calculate()` получает строку из `radiusInput`. Пустая строка сразу вызывает Toast.
3. Запятая заменяется точкой, затем `Double.parseDouble()` преобразует строку в число. Ошибка преобразования перехватывается.
4. Число должно быть больше нуля и конечным. Для слишком большого числа дополнительно проверяется конечность каждого результата.
5. `calculateCircle(double radius)` возвращает массив из диаметра `2r`, длины `2πr` и площади `πr²`.
6. `String.format()` выводит каждое значение с двумя знаками после запятой. Для результата задан русский формат, поэтому десятичный разделитель всегда запятая.

При неверном вводе `showError()` очищает предыдущие результаты и показывает Toast. Для нового ответа нужно ввести корректный радиус и снова нажать кнопку.
