# Параметры окружности

Приложение для Android вычисляет диаметр, длину и площадь окружности по радиусу. Вводите положительное число. Десятичная точка и запятая допускаются. Результаты показаны с двумя знаками после запятой и десятичной запятой.

## Как собрать APK в Android Studio

1. Откройте папку проекта `CircleCalculator` в Android Studio и дождитесь завершения синхронизации Gradle.
2. Убедитесь, что выбрана конфигурация модуля `app` и вариант сборки `debug`.
3. Откройте меню **Build → Generate Bundle(s) / APK(s) → Generate APK(s)**. В некоторых версиях Android Studio эти пункты называются **Build Bundle(s) / APK(s) → Build APK(s)**.
4. Дождитесь сообщения об успешной сборке и нажмите **Locate** в уведомлении. APK находится в папке `app/build/outputs/apk/debug/` и называется `app-debug.apk`.

Для сборки эмулятор и телефон не нужны. Отладочный APK уже подписан стандартным ключом Android SDK и подходит для установки на телефон при проверке работы приложения.

Тот же APK можно получить из терминала Windows, открытого в корне проекта:

```powershell
.\gradlew.bat assembleDebug
```

После выполнения команды файл появится по пути `app/build/outputs/apk/debug/app-debug.apk`. Если проект скачан с GitHub, сначала распакуйте его и откройте распакованную папку в Android Studio. Нужны установленные Android Studio и Android SDK; при первом открытии Gradle может загрузить зависимости.

Не используйте кнопку **Run** для получения файла, который будете переносить на телефон вручную: APK, созданный этим действием, может иметь признак `testOnly`. Для переносимого файла используйте команду сборки APK из меню или `assembleDebug`.

## Установка APK на телефон

1. Убедитесь, что на телефоне установлена Android 11 или новее.
2. Перенесите собранный `app-debug.apk` на телефон и откройте его. Если вам отдельно передали `CircleCalculator-debug.apk`, это готовая копия того же отладочного APK.
3. Если Android попросит разрешить установку из этого источника, разрешите её для приложения, которым открываете APK.
4. Нажмите «Установить», затем откройте «Параметры окружности».

При установке вне магазина приложений телефон может показать предупреждение об источнике файла.

## Запуск через Android Studio

1. Откройте эту папку как проект в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Выберите эмулятор с Android 11 или новее либо подключённый телефон с включённой отладкой по USB.
4. Нажмите **Run** для конфигурации `app`.

Проект использует Java, XML-разметку и минимальный SDK API 30. Интернет для работы приложения не нужен.

## Использование

Введите радиус и нажмите «Рассчитать». При пустом поле, неверном формате, нуле, отрицательном или слишком большом радиусе появляется короткое сообщение об ошибке.

Подробное объяснение файлов и логики находится в `КАК_РАБОТАЕТ_КОД.md`.
